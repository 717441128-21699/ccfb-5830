# 多路庭审同步回放台

浏览器内多机位同步回放工具:导入多路视频/音频后,用音频互相关自动对齐各机位开机时差,
统一时间轴同步回放,支持书签备注与画中画导出。纯前端,无需服务器,素材不出本机。

## 快速开始

```bash
npm install
npm run dev          # http://localhost:5173
```

点 **载入示例素材** 加载合成测试片(3 路摄像头 + 1 路录音笔,开机时间互差数秒,
画面烧有会话时间码),或点 **导入音视频** 选择自己的文件(MP4/MOV/MP3/WAV/M4A 等)。

重新生成测试素材:`bash scripts/make_sample_media.sh`(需要 ffmpeg + python3)。

## 功能与操作

- **自动对齐**:GCC-PHAT 音频互相关,以最长轨道为基准解出各路偏移(精度 <1ms),
  报告给出相关峰与置信度;对齐后可点任意轨道"设为基准(归零)"平移整个会话原点。
- **手动微调**:轨道面板 ±1帧/±10ms/±100ms 按钮,或直接拖动时间线上的轨道条。
- **同步回放**:主时钟驱动,PI 控制(软变速 ±20% + 积分管线延迟补偿 + 硬 seek 兜底),
  轨道卡片实时显示估算的感知音画漂移;空格播放/暂停,←/→ ±1s(Shift ±5s)。
- **主画面/小窗**:点击小窗提升为主画面;"出声轨道"任选一路(默认录音笔)。
- **书签备注**:B 键或"＋当前时间",时间线上显示彩钉,点击跳转,备注自动保存。
- **导出**:设入点/出点([ / ] 键),导出 1280×720@30 画中画 MP4(H.264 + AAC):
  主画面全幅 + 其余机位右下角竖排小窗,左上角烧轨道名与会话时间码。
  偏移、书签、选区按素材组合自动存入 localStorage,下次载入自动恢复。

## 架构

```
src/
  fft.ts       基-2 FFT + GCC-PHAT 互相关(8kHz 单声道, 抗混响)
  audio.ts     整轨解码(decodeAudioData)、降采样、自动对齐编排
  sync.ts      主时钟同步引擎(PI 控制, 硬 seek 冷却, 起播前等各轨 seek 落定)
  timeline.ts  Canvas 时间线:标尺/轨道条拖拽/选区/书签/播放头,滚轮缩放
  demux.ts     mp4box 解封装, 取 H.264 样本流(含 edit list 呈现零点归一化)
  export.ts    WebCodecs 逐轨解码 → OffscreenCanvas 画中画合成 →
               VideoEncoder/AudioEncoder → mp4-muxer 封装
  main.ts      UI 装配、轨道面板、书签、持久化
test/
  align.test.ts   对齐算法单测(node 直接跑, 已知偏移回放)
  e2e.mjs         端到端:对齐精度/播放漂移/导出产物校验(驱动本机 Chrome)
  debug-*.mjs     排查用脚本(导出/同步内部状态观测)
scripts/
  gen_tc.py           烧会话时间码的 RGBA 条带生成器(纯 stdlib)
  make_sample_media.sh 合成 3 路摄像头 + 1 路录音笔测试素材
```

## 关键取舍

- **对齐基准**:自动对齐保持最长轨道(通常是录音笔)的偏移为 0,其余轨道相对它定位;
  会话原点因此是"最早开机时刻",与任一路烧录时间码无关,需要时一键归零重定原点。
- **互相关采样率 8kHz**:啁啾/语音能量集中在 4kHz 以下,精度 0.125ms 足够,FFT 规模可控。
- **同步策略**:起播前先让各轨 seek 落定再启动主时钟(否则 seek 空窗被误判为漂移,
  引发"漂移→seek→更漂"的恶性循环);稳态只靠 ±20% 软变速,硬 seek 留给 >100ms 的灾难偏离。
- **导出仅支持 H.264 的 MP4/MOV**;浏览器不支持 AAC 编码时(如无头 Chrome)自动降级为
  无声导出并在状态栏说明。导出音画对齐由容器时间戳保证(帧 i → i/fps,音频块按采样计数)。
- **edit list 修正**:H.264 B 帧使首帧 cts=+2 帧,不解会让导出画面整体晚 2 帧;
  按"最小 cts = 呈现零点"归一化。

## 测试

```bash
node test/align.test.ts   # 算法单测: 已知偏移 ±0.00ms
npm run dev &             # e2e 需要 dev server
node test/e2e.mjs         # 全链路: 偏移解算 / 漂移 / 导出
```

当前 e2e 基线:相对偏移误差 0.000s;稳态漂移 ≤20ms(一帧@25fps = 40ms 的一半以内);
导出 5s 片段时长精确、各流 start_time≈0、烧录时间码与会话时间逐帧一致。
